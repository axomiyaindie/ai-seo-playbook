# Contributing

Thanks for helping build the open AI SEO playbook.

## Rules for every tactic
1. **What** it is · 2. **Why** it works · 3. **How** to do it · 4. **How to verify**
5. Label evidence: `Proven` (documented by the platform), `Likely` (strong consistent studies), `Experimental` (unverified)
6. Link primary sources (official docs, studies) and add the date verified.
7. No spam, fake-review or manipulation tactics.

## Process
Fork → branch → edit → pull request. Small PRs welcome: typo fixes, new sources, updated bot lists, case studies.

# 04 · Content

## Make content citable
- Lead with the answer, then explain.
- One clear claim per paragraph, with numbers, dates and sources.
- Use question-style H2/H3 headings that match real prompts.
- Add comparison tables, pros/cons, pricing, specs, "best for" statements.
- Show real authors, credentials, first-hand experience (E-E-A-T).
- Publish things only you can: original research, case studies, tools, templates.

## Build entity and brand authority
- Consistent name, description and facts: site, LinkedIn, GitHub, Crunchbase, G2, Product Hunt, app stores, Wikidata if eligible.
- Earn mentions in places AIs read: Reddit, Quora, YouTube, review sites, newsletters, press, docs sites.
- Ask real customers for reviews on third-party platforms.

## Prompt research
List the questions your buyers ask AIs ("best X for Y", "X alternatives", "is X worth it") and create a page for each.

## Avoid
Fake reviews, hidden text, mass AI-generated filler, prompt-injection tricks aimed at LLMs. They get penalized and erode trust.

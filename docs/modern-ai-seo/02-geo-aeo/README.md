# 02 · GEO and AEO

## Core tactics
| Tactic | Status | How |
|---|---|---|
| Answer-first writing | Likely | Put a direct 40–60 word answer under each question heading |
| Original data and stats | Likely | Publish benchmarks, surveys, studies others will cite |
| Clear definitions | Likely | "X is a ... that ..." sentences LLMs can lift |
| Comparison pages | Likely | "X vs Y", "best X for Y", with honest tables |
| Third-party mentions | Likely | Reviews, Reddit, YouTube, press, directories |
| Freshness | Likely | Visible updated dates, maintained pages |
| Structured data | Proven for rich results; uncertain for LLMs | Use accurate schema anyway |
| Brand consistency | Likely | Same name, description, facts across the web |

## Per-platform notes (verify and update regularly)
- **Google AI Overviews / AI Mode**: standard Google indexing and ranking signals; being indexed and snippet-eligible is required. No special markup.
- **ChatGPT search**: allow `OAI-SearchBot` to appear in search results; `GPTBot` is for training.
- **Perplexity**: allow `PerplexityBot`; favors clear, recent, authoritative pages.
- **Claude**: `Claude-SearchBot` (search), `ClaudeBot` (training), `Claude-User` (user-triggered fetch).
- **Gemini / Copilot**: rely on Google and Bing indexes respectively.

> Bot names and behaviors change. Always confirm in each vendor's official docs. See [technical](../03-technical/README.md).

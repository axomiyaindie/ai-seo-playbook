# 05 · Measurement

| What | How |
|---|---|
| Citations / mentions | Run a fixed prompt set weekly across ChatGPT, Perplexity, Gemini, Claude, Google AI Mode; log in [templates/prompt-tracker.csv](../../templates/prompt-tracker.csv) |
| AI referral traffic | Analytics: segment referrers like chatgpt.com, perplexity.ai, gemini.google.com, copilot.microsoft.com, claude.ai |
| Crawl activity | Server logs: filter by the bots in [technical](../03-technical/README.md) |
| Classic SEO | Google Search Console, Bing Webmaster Tools |
| Share of voice | % of tracked prompts where you are mentioned vs competitors |

AI answers are non-deterministic: repeat each prompt several times and track trends, not single results.

# 06 · What's next

Emerging areas to watch and document (community: please add sourced updates):

- **AI agents that act**: browsing, booking, buying on a user's behalf; sites must be agent-readable.
- **Agentic commerce**: product feeds and checkout protocols inside AI assistants.
- **MCP and tool access**: exposing product data or APIs to assistants via the Model Context Protocol.
- **AI Mode and conversational search**: longer multi-step queries; query fan-out.
- **Personalized, memory-based answers**: less deterministic rankings.
- **Licensing and crawl controls**: pay-per-crawl, bot authentication, new robots standards.
- **Multimodal search**: images, video and voice as citation sources.

Format for each entry: what it is · who supports it · date verified · what to do now.
